# Personal Portfolio Website
🌐 [damiankakkarjohnson.dev](https://damiankakkarjohnson.dev/)

A responsive personal portfolio website where anyone can learn about my experience, projects, volunteering, and skills.

## Tech Stack
- **React.js** — component architecture, useState hook
- **CSS3** — Flexbox, media queries, animations, pseudo-elements
- **HTML5** — semantic markup
- **Vite** — build tool and dev server

## Features
- Responsive design that adapts to all screen sizes
- Mobile-friendly hamburger navigation menu
- Interactive card hover animations
- Consistent reusable component architecture

## Sections
- **Intro** — brief introduction and social links
- **Experience** — work history with company links
- **Projects** — personal and academic projects with tech stack tags
- **Leadership** — volunteering and community involvement
